Why must the baseline's expectation go to zero?

A policy-gradient learner scores each attempt and subtracts a baseline before learning from it. This page derives the one condition that subtraction must satisfy, then checks Dr. GRPO and GRPO against it, line by line.

reward \(r\) baseline \(b\) weight \(w = r - b\), positive weight, negative

1Why subtract anything?

A student's essays usually score about 7 out of 10. Today's essay scores 7. That is what was going to happen anyway, so it carries no news. An 8.3 does: whatever was different today is worth repeating. So does a 5.6.

The informative part of a score is the gap between what happened and what was expected. The expectation is the baseline \(\bs{b}\). The gap is what the model should learn from. Call it the weight \(\sg{w}\), because it is the number that will multiply each response in the update:

\[ \sg{w} \;=\; \rw{r} - \bs{b} \]

Below, a model has answered one prompt eight times and a grader has given each response a score from 0 to 10. These eight scores are the running example for the whole page.

Where the weight is used

Call the prompt \(q\). The model, with parameters \(\theta\), gives response \(o\) to that prompt with probability \(\pi_\theta(o\mid q)\). Everything on this page concerns one fixed prompt, so \(q\) is dropped from the notation and the probability is written \(\pi_\theta(o)\). It reappears only where a formula needs it. Training wants to raise the expected reward:

\[ J(\theta) \;=\; \E_{o\sim\pi_\theta}\big[\rw{r(o)}\big] \;=\; \sum_o \pi_\theta(o)\,\rw{r(o)} \]

Differentiate, and use \(\nabla\pi = \pi\,\nabla\log\pi\) to turn the result back into an expectation that can be estimated by sampling:

\[ \nabla J \;=\; \sum_o \nabla\pi_\theta(o)\,\rw{r(o)} \;=\; \sum_o \pi_\theta(o)\,\nabla\log\pi_\theta(o)\,\rw{r(o)} \;=\; \E\big[\,\rw{r(o)}\;g(o)\,\big] \]
\[ \text{where}\qquad g(o) \;:=\; \nabla_\theta\log\pi_\theta(o) \]

\(g(o)\) is called the score function. It is the direction in parameter space that makes response \(o\) more likely. So the gradient says: sample responses, and move along each one's \(g\), weighted by its reward.

The expectation cannot be computed exactly, because it runs over every possible response. Replace it with an average over \(G\) sampled responses \(o_1,\dots,o_G\) with rewards \(\rw{r_1},\dots,\rw{r_G}\):

\[ \widehat{\nabla J}_{b=0} \;=\; \frac{1}{G}\sum_{i=1}^{G}\rw{r_i}\;g(o_i), \qquad \E\big[\widehat{\nabla J}_{b=0}\big] = \nabla J \]

Two pieces of notation. The hat means "an estimate of", so \(\widehat{\nabla J}\) is an estimate of the gradient \(\nabla J\) built from samples. The subscript \(b=0\) says that nothing has been subtracted from the rewards.

This estimate has no baseline in it. It is the "Weight = r" setting in the figure above, and the figure shows its weakness: the weights are large and nearly equal, so most of each one is the part all responses share. The essay example suggests the repair, which is to weight by \(\rw{r}-\bs{b}\) instead. But \(\nabla J = \E[\rw{r}\,g]\) says nothing about a baseline. Before using one, we have to check that it is allowed.

Takeaway

The gradient of expected reward is \(\E[r\,g(o)]\): move along each sampled response's score function, weighted by its reward. A baseline would change the weight from \(r\) to \(r-b\). Whether that still gives the gradient is the next question.

2Why must the expectation be zero?

Start with the exact gradient, before any sampling. Put the baseline inside the expectation, replacing \(\rw{r}\) by \(\rw{r}-\bs{b}\), and split the result:

\[ \E\big[(\rw{r}-\bs{b})\,g(o)\big] \;=\; \underbrace{\E\big[\rw{r}\,g(o)\big]}_{=\;\nabla J} \;-\; \underbrace{\E\big[\bs{b}\,g(o)\big]}_{\text{must be } 0} \]

The first term is the true gradient. So \(\nabla J = \E[(\rw{r}-\bs{b})\,g(o)]\) exactly when the second term vanishes. That is the zero in this page's title:

\[ \textbf{Unbiasedness condition:}\qquad \E\big[\,\bs{b}\;g(o)\,\big] \;=\; 0 \]

Why it holds for a constant baseline

The score function has mean zero under the model's own sampling, because probabilities sum to one:

\[ \E_{o\sim\pi}\big[g(o)\big] \;=\; \sum_o \pi(o)\,\frac{\nabla\pi(o)}{\pi(o)} \;=\; \nabla\sum_o \pi(o) \;=\; \nabla 1 \;=\; 0 \]

If \(\bs{b}\) is the same number whichever response is sampled, it factors out: \(\E[\bs{b}\,g(o)] = \bs{b}\,\E[g(o)] = 0\). If \(\bs{b}\) changes with the sampled response, it cannot be factored out and the term survives. Since \(\E[g]=0\), the condition is the same as saying \(\operatorname{Cov}(\bs{b},\,g)=0\): a baseline is valid exactly when it is uncorrelated with the score function.

A two-response example makes this concrete. The model gives response X with probability \(p=0.3\) and Y with probability \(0.7\), controlled by one parameter \(\theta\) with \(p=\operatorname{sigmoid}(\theta)\). Then \(g(X) = 1-p = +0.7\) and \(g(Y) = -p = -0.3\).

\[ \begin{aligned} \text{mean of } g: &\quad 0.3(+0.7) + 0.7(-0.3) = 0\\[2pt] \bs{b}=5 \text{ for both}: &\quad 0.3(5)(+0.7) + 0.7(5)(-0.3) = 1.05 - 1.05 = 0\\[2pt] \bs{b}=6 \text{ for X},\ 3 \text{ for Y}: &\quad 0.3(6)(+0.7) + 0.7(3)(-0.3) = 1.26 - 0.63 = +0.63 \end{aligned} \]

From the expectation to the sample estimate

With a baseline that meets the condition, the gradient can be written with the baseline inside it, and then estimated from \(G\) samples exactly as before:

\[ \nabla J \;=\; \E\big[(\rw{r}-\bs{b})\,g(o)\big] \]
\[ \widehat{\nabla J} \;=\; \frac{1}{G}\sum_{i=1}^{G}\big(\rw{r_i} - \bs{b}\big)\,g(o_i) \;=\; \frac{1}{G}\sum_{i=1}^{G}\sg{w_i}\;g(o_i) \]

For a baseline that is a fixed number, \(\E[\widehat{\nabla J}]=\nabla J\), the same as for \(\widehat{\nabla J}_{b=0}\). One caution for later. In practice \(\bs{b}\) is often computed from the same \(G\) samples. Then it is not a fixed number, and the condition has to be checked again for the estimator itself. Sections 3 and 4 do that for Dr. GRPO and GRPO.

A second, weaker zero: centring

The weight itself has expectation \(\E[\sg{w}] = \E[\rw{r}] - \bs{b}\). That is zero only for one choice of baseline, the expected reward for this prompt:

\[ \textbf{Centring:}\qquad \E[\sg{w}] = 0 \;\iff\; \bs{b} = \E_{o\sim\pi}[\rw{r(o)}] =: V \]

With that particular baseline the weight has a name. \(A(o) := \rw{r(o)} - V\) is the advantage of response \(o\): how much better it is than the policy's average. The advantage has mean zero by definition. So centring can be read as: choose \(\bs{b}\) so that the weight is the advantage. For any other \(\bs{b}\), the weight is the advantage plus a constant offset.

Centring is not needed for unbiasedness. Any constant \(\bs{b}\) gives the right gradient on average. What centring controls is noise. Write \(\bs{b} = V - c\), so every weight is \(\sg{w} = A + c\). The estimator gains the term \(\frac{c}{G}\sum_i g(o_i)\), which has mean zero but does not vanish for finite \(G\). It pushes towards whatever happened to be sampled.

The figure isolates that term. Four answers all earn reward \(r = 1\), so \(V=1\), every advantage is zero, the true gradient is zero, and the model should not change. Each step samples one answer \(a\) and applies \(\theta \leftarrow \theta + 0.3\,(1-\bs{b})\,g(a)\).

With \(\sg{w}=+1\), each sampled answer is pushed up, which makes it more likely to be sampled and pushed up again. The policy collapses onto one arbitrary answer. With \(\sg{w}=-1\), each sampled answer is pushed down and the policy jitters. In both cases the expected update is zero, as the lemma promises. This is variance, not bias, and it is what an off-centre baseline costs.

We want learning to be driven by relative performance, not systematic offsets.

Takeaway

Unbiasedness needs \(\E[b\,g(o)] = 0\), which holds when \(b\) does not vary with the sampled response. Centring, \(\E[w]=0\), needs \(b = \E[r] = V\), and then the weight is the advantage \(A = r - V\). The first decides whether the update points the right way. The second decides how noisy it is.

3Dr. GRPO, checked against both

The ideal baseline \(V=\E[r]\) is unknown. Dr. GRPO estimates it from the samples it already has: the mean reward of the group of \(G\) responses to the prompt.

\[ \bs{\bar r} = \frac{1}{G}\sum_{j=1}^{G}\rw{r_j}, \qquad \sg{\hat A_i} = \rw{r_i} - \bs{\bar r}, \qquad \widehat{\nabla J}_{\text{Dr}} = \frac{1}{G}\sum_{i=1}^{G}\big(\rw{r_i} - \bs{\bar r}\big)\,g(o_i) \]

As before, the hat means "an estimate of". \(\bs{\bar r}\) estimates \(V\), so \(\sg{\hat A_i}\) estimates the advantage \(A(o_i) = r_i - V\).

A response is written one token at a time. Write \(o_{i,t}\) for token \(t\) of response \(i\), \(o_{i,<t}\) for the tokens of that response before it, and \(|o_i|\) for the number of tokens. Each token is drawn given the prompt \(q\) and the tokens so far, so the probability of the whole response is a product:

\[ \pi_\theta(o_i) \;=\; \pi_\theta(o_i\mid q) \;=\; \prod_{t=1}^{|o_i|}\pi_\theta\big(o_{i,t}\mid q,\,o_{i,<t}\big) \]

Taking the logarithm turns the product into a sum, so the score function of a response is a sum over its tokens:

\[ g(o_i) \;=\; \nabla_\theta\log\pi_\theta(o_i) \;=\; \sum_{t=1}^{|o_i|}\nabla_\theta\log\pi_\theta\big(o_{i,t}\mid q,\,o_{i,<t}\big) \]

Dr. GRPO uses that sum as it is.

Centring

It holds exactly, in every group and not only on average: \(\sum_i \sg{\hat A_i} = \sum_i \rw{r_i} - G\,\bs{\bar r} = 0\).

Unbiasedness

The condition asked for a baseline that does not vary with the sampled response. \(\bs{\bar r}\) contains \(\rw{r_i}\), so it does vary with \(o_i\). The figure shows this: change one reward and its own baseline moves. Separate that reward out. Let \(\bs{\bar r_{-i}}\) be the mean of the other \(G-1\) rewards. Then

\[ \bs{\bar r} = \frac{\rw{r_i} + (G-1)\,\bs{\bar r_{-i}}}{G} \quad\Longrightarrow\quad \rw{r_i} - \bs{\bar r} \;=\; \frac{G-1}{G}\,\big(\rw{r_i} - \bs{\bar r_{-i}}\big) \]

The responses are sampled independently, so \(\bs{\bar r_{-i}}\) is independent of \(o_i\) and passes the condition: \(\E[\bs{\bar r_{-i}}\,g(o_i)] = \E[\bs{\bar r_{-i}}]\cdot\E[g(o_i)] = 0\). Therefore

\[ \E\big[\widehat{\nabla J}_{\text{Dr}}\big] \;=\; \frac{G-1}{G}\Big(\E\big[\rw{r}\,g(o)\big] - 0\Big) \;=\; \frac{G-1}{G}\,\nabla J \]

The expected update is the true gradient times a fixed number: 7/8 when \(G=8\). The direction is exact. The length is absorbed by the learning rate. Tick the box in the figure to see the same fact: every filled bar is 7/8 of its outline.

Assumptions

The derivation used three. The \(G\) responses are independent samples from \(\pi_\theta\) for the same prompt. Each \(r_i\) depends only on \(o_i\), not on the other responses. And the \(\theta\) being differentiated is the \(\theta\) that produced the samples. The last is exact on the first gradient step for a batch. Later steps reuse the samples through a clipped probability ratio \(\pi_\theta/\pi_{\text{old}}\), which keeps it approximately true.

Takeaway

Dr. GRPO: \(b=\bar r\). Centred exactly. Unbiased up to the constant \((G-1)/G\), because \(r_i-\bar r\) is a rescaled copy of the leave-one-out estimate \(r_i - \bar r_{-i}\).

4GRPO, checked against both

GRPO uses the same group mean and then applies two more operations. It divides \(\sg{\hat A_i}\) by the group's standard deviation \(\gp{\sigma}\), and it averages the token-level score terms over the response length \(\gp{|o_i|}\) where Dr. GRPO sums them.

\[ \frac{\sg{\hat A_i}}{\gp{\sigma}} = \frac{\rw{r_i} - \bs{\bar r}}{\gp{\sigma}},\qquad \gp{\sigma} = \sqrt{\tfrac{1}{G}\textstyle\sum_j (\rw{r_j} - \bs{\bar r})^2} \]
\[ \begin{aligned} \widehat{\nabla J}_{\text{GRPO}} \;&=\; \frac{1}{G}\sum_{i=1}^{G}\,\gp{\frac{1}{|o_i|}}\sum_{t=1}^{|o_i|}\frac{\sg{\hat A_i}}{\gp{\sigma}}\;\nabla\log\pi_\theta(o_{i,t}\mid q,o_{i,<t}) \\[4pt] &=\; \frac{1}{G}\sum_{i=1}^{G}\frac{\rw{r_i}-\bs{\bar r}}{\gp{\sigma\,|o_i|}}\;g(o_i) \end{aligned} \]

(Both methods also wrap this in a clipped ratio, and GRPO adds a KL penalty. Neither changes the analysis here.)

Centring

It still holds exactly. \(\sum_i \sg{\hat A_i}/\gp{\sigma} = \frac{1}{\gp{\sigma}}\sum_i(\rw{r_i}-\bs{\bar r}) = 0\).

Unbiasedness: the two extra factors

Compared with Dr. GRPO, response \(i\)'s weight is multiplied by \(1/(\gp{\sigma}\,\gp{|o_i|})\). A constant multiplier would be harmless, as \((G-1)/G\) was. Neither of these is constant.

The factor \(1/\gp{\sigma}\) varies from prompt to prompt. The slider rescales how far apart the eight rewards are, keeping their order and their mean.

A prompt where the eight responses scored within a few tenths of each other produces the same size update as one where they ranged over six points. Write \(J_q\) for the expected reward on prompt \(q\) alone, and \(\gp{\sigma_q}\) for that prompt's reward spread. Averaged over prompts, the expected update is roughly

\[ \E\big[\widehat{\nabla J}\big] \;\approx\; \E_q\!\Big[\frac{1}{\gp{\sigma_q}}\,\nabla J_q\Big] \quad\text{in place of}\quad \E_q\big[\nabla J_q\big] \]

so prompts are reweighted by \(1/\gp{\sigma_q}\). The prompts with the smallest spread are those the model handles almost uniformly well or uniformly badly, and they get the largest weight. (It is "roughly" because \(\gp{\sigma}\) also contains \(r_i\), so within a prompt it is not quite a constant either.)

The factor \(1/\gp{|o_i|}\) varies from response to response. This is the more serious one, because it depends on the very response being weighted.

Section 1 showed \(\nabla\E[r(o)] = \E[r(o)\,g(o)]\). The same steps work for any function \(f\) of the response: \(\nabla\E[f(o)] = \E[f(o)\,g(o)]\). Treat the leave-one-out baseline \(b\) as fixed and take \(f = (r-b)/|o|\):

\[ \E\Big[\frac{\rw{r}-\bs{b}}{\gp{|o|}}\,g(o)\Big] \;=\; \nabla\,\E\Big[\frac{\rw{r}-\bs{b}}{\gp{|o|}}\Big] \;=\; \underbrace{\nabla\,\E\Big[\frac{\rw{r}}{\gp{|o|}}\Big]}_{\text{not }\nabla J} \;-\; \underbrace{\bs{b}\;\nabla\,\E\Big[\frac{1}{\gp{|o|}}\Big]}_{\text{baseline term, not }0} \]

The baseline term no longer vanishes. The unbiasedness condition fails. What GRPO climbs is "reward above baseline, per token": a response above the baseline raises it most by being short, and a response below the baseline hurts it least by being long. Over training this favours short good answers and long bad ones.

Assumptions

GRPO would be unbiased under Dr. GRPO's assumptions plus two more: all responses have the same length, and every prompt has the same reward spread. Neither holds in practice.

The two factors have practical motives. Dividing by \(\gp{\sigma}\) makes the update invariant to the grader's scale. Dividing by \(\gp{|o_i|}\) stops long responses dominating a batch. Both are bought with bias.

Deeper mathematical note pass/fail rewards as a special case

Many graders return only \(r\in\{0,1\}\). If \(k\) of \(G\) responses pass, let \(f=k/G\) be the fraction that pass. Then \(\bar r = f\) and \(\sigma=\sqrt{f(1-f)}\). A passing response gets \(\hat A/\sigma=\sqrt{(1-f)/f}\) and a failing one \(-\sqrt{f/(1-f)}\). The prompt's multiplier \(1/\sigma\) is smallest, 2, at \(f=\tfrac12\) and grows without bound as \(f\to 0\) or \(1\): for \(G=8\) it is about 3.02 at \(k=1\) or \(7\). When \(k=0\) or \(k=G\), \(\sigma=0\) and every \(\hat A_i\) is zero in both methods (implementations add a small \(\varepsilon\) to the denominator).

Why centring still matters for noise: with a constant offset \(c\), the extra term \(\tfrac{c}{G}\sum_i g(o_i)\) has variance \(c^2\,\E\lVert g\rVert^2/G\). The choice \(b=V\) removes it.

Takeaway

GRPO: same baseline, still centred. Its weight is \((r_i-\bar r)/(\sigma\,|o_i|)\). The \(1/\sigma\) factor reweights prompts. The \(1/|o_i|\) factor depends on the response itself, so \(\E[b\,g]\) no longer vanishes.

Remember this

The baseline approximates \(V=\E[r]\), the reward the model would have earned on this prompt anyway.

Two expectations should be zero. \(\E[b\,g]=0\) keeps the update pointing along \(\nabla J\). \(\E[w]=0\) keeps offsets from adding noise, and holds when the weight \(w=r-b\) is the advantage \(A=r-V\).

Both methods use \(b=\bar r\) and both are centred. Dr. GRPO stops there and is unbiased up to \((G-1)/G\). GRPO divides by \(\sigma\) and \(|o_i|\), and those two factors are its bias.
